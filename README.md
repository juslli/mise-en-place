# Mise en Place

Aplicativo web de receitas desenvolvido para organizar, pesquisar e gerenciar receitas em um só lugar.

## Funcionalidades

- Cadastro, edição e exclusão de receitas.
- Organização por categorias e coleções.
- Pesquisa e ordenação de receitas.
- Busca de receitas online.
- Importação e exportação de receitas para backup.
- Assistência na organização de legendas de receitas do Instagram.
- Armazenamento local das receitas no navegador.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Node.js

## Acesse o projeto

**Aplicação online:** https://mise-en-place-12u8.onrender.com/

## Executar localmente

1. Clone este repositório.
2. Instale o Node.js versão 20 ou superior.
3. Abra o terminal na pasta do projeto.
4. Execute:

```bash
npm start
```

5. Acesse `http://localhost:3000` no navegador.

## Observação

As receitas são armazenadas localmente no navegador. Atualmente, os dados não são sincronizados automaticamente entre dispositivos.
